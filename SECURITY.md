# Security policy

## Supported versions

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Do not report vulnerabilities in public issues. Use GitHub's private
vulnerability reporting for this repository. Include affected versions,
reproduction steps, impact, and any suggested mitigation. The maintainers will
acknowledge reports as soon as practical and coordinate disclosure after a fix
is available.

Do not include real credentials, production database contents, or personal data
in a report.
