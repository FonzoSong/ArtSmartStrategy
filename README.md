# 艺数智策

面向艺术团队的自有数据运营复盘 Web 网站。当前版本为无需安装依赖的静态网页演示项目，内置 3 条通用示例记录。

## 本地运行

在项目目录执行：

```bash
python3 -m http.server 8000
```

然后用浏览器打开 <http://localhost:8000>。也可以将 `index.html` 直接拖入浏览器打开。

## 已实现

- 运营总览、平台表现、内容记录、分类及时段分析、排期建议和周历。
- 手动录入、编辑、删除及 CSV 批量导入；可下载 CSV 模板。
- 运营复盘文本和排期 CSV 导出。
- 兼容 OpenAI Chat Completions 格式的自定义模型接口设置与连接测试。
- 本地浏览器保存记录和接口设置；响应式布局适配手机。
- 宣纸米色、石青与朱砂配色，示例内容使用通用标题与平台占位名称。

## 演示版说明

所有业务记录保存在浏览器 `localStorage` 中，不会自动上传。截图入口提供人工核对录入流程，不调用 OCR 服务；模型建议页面使用内置的基础参考文案，配置接口后可测试连通性。若要让模型实际参与建议生成，需要根据所选服务的接口格式接入生成请求，并考虑服务端代理及密钥保护。
