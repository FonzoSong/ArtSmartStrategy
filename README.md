# 艺数智策

面向艺术团队的自有数据复盘 Web 应用。只分析团队主动录入的数据，不抓取外部内容，也不采集观众个人隐私。界面和分析结论都按小样本场景设计，样本不足时会明确提示。

## 三步启动

### Docker Compose

需要 Docker Engine 和 Docker Compose。

```bash
cp .env.example .env
```

编辑 `.env`，将 `APP_SECRET` 改成随机长字符串；若启用 AI，再填写 `AI_BASE_URL`、`AI_API_KEY` 和 `AI_MODEL`。然后启动服务：

```bash
docker compose up --build
```

浏览器打开 <http://localhost:8000>。首次打开时创建团队负责人账号。SQLite 数据保存在 `data/arts_smart.db`，容器重建不会清除。

### 本地手动运行

需要 Python 3.11 或更高版本。Linux / macOS：

```bash
cp .env.example .env
```

把 `.env` 中的 `APP_SECRET` 改成随机长字符串。然后运行启动脚本：

```bash
./start.sh
```

脚本会建立虚拟环境、安装依赖、执行数据库迁移并启动服务。浏览器打开 <http://127.0.0.1:8000>，首次创建团队负责人账号。Windows 可双击 `start.bat`，首次启动前复制 `.env.example` 为 `.env` 并修改密钥。

需要在内网以外访问时，请使用 HTTPS 反向代理并设置强随机 `APP_SECRET`；不要把服务端口直接暴露到公网。

## 首次使用

首次打开创建团队名称、负责人姓名、邮箱与至少 10 位密码。负责人可以创建录入者和查看者账号。查看者由服务端拒绝写入请求。新团队可以在登录页创建独立空间；各团队数据按团队 ID 隔离，账号密码使用 PBKDF2 哈希，登录会话有效期为 14 天。

首次安装会载入 3 条通用示例记录。可在内容记录页补充、编辑或删除记录；“重置体验数据”会清空当前团队数据。数据库文件备份路径为 `data/arts_smart.db`。

## 功能

- **运营总览**：真实数据库 KPI、趋势、平台表现、优质内容、数据完整度、采纳收益、转化漏斗和节奏提醒。
- **内容记录**：手动录入、CSV 批量导入、Tesseract 截图 OCR 草稿预览与确认、去重提示、标签、素材说明、负责人、备注和六阶段生命周期。
- **效果分析**：类型与平台对比、星期和时段热力、团队自身历史中位数、可编辑基准、综合表现权重、转化漏斗、评论关键词与情感提示。
- **排期建议**：基于团队记录生成结构化 AI 建议。没有模型配置、网络失败或调用失败时，会自动切换为规则统计建议，并显示来源与降级原因。可设置多套模型，保存后由后端代理请求。
- **排期日历**：采纳建议写入 SQLite，支持周视图、列表、拖动改期、手动调整、发布回填和预测偏差反馈。
- **报告与交接**：后端生成含数据图形的 PDF 复盘报告；可导出脱敏 CSV 和 Markdown 换届交接包。
- **账号与审计**：团队隔离、负责人 / 录入者 / 查看者角色、关键操作审计记录。

## 小样本口径

默认最小样本门槛是 **5 条**，可以在“模型接口设置 → 分析口径”调整。

- 少于门槛：分类、平台和时段的平均值显示“样本不足”，不会送入模型的稳定规律摘要。
- 门槛至两倍门槛：标注“样本较少，仅供参考”。
- 记录总数、单条内容值等原始事实仍可查看。
- 跨平台播放与互动口径可能不同，页面会提醒谨慎比较。综合分默认权重为看完比例 0.68、互动表现 1.15；也可按平台填写权重模板。
- 所有建议都显示参考条数和信心等级。规则建议会从团队实际记录提炼类型、平台、星期和时段；样本不足时不会声称存在稳定规律。

## 模型配置与隐私

“模型接口设置”支持 OpenAI 官方、DeepSeek、通义千问、智谱、Moonshot 和自定义服务，包含基础地址 / 完整请求路径、Bearer / api-key 鉴权、温度、连通测试、失败降级及多配置切换。浏览器只向本应用后端发请求，API Key 保存在服务端 SQLite 或 `.env`，不会放进前端存储。建议只配置自己信任的服务商，并了解其数据处理政策。

不配置模型时，系统仍可离线运行规则分析、手动录入、CSV 导入、日历、PDF 报告和本地 OCR。首次安装依赖需要联网；安装后不需要联网即可使用本地功能。若启用远程模型，内容摘要会发送给你设置的服务商。

OCR 使用本机 Tesseract 和中文语言包，不将截图上传到 OCR 云服务。Docker 镜像已经安装 OCR 运行组件；本地运行需要额外安装系统 Tesseract（含 `chi_sim` 中文语言包）。平台截图样式各异，OCR 结果必须人工核对后才会入库。

## 阶段自测

启动后可在另一个终端运行完整隔离式自测。测试使用临时 SQLite 文件和本地模拟模型服务，不修改正式 `data/arts_smart.db`，也不需要真实 API Key。

```bash
.venv/bin/python scripts/selftest.py
```

Windows：

```powershell
.venv\Scripts\python scripts\selftest.py
```

通过时应显示 `27 end-to-end checks passed.`。测试包括账号登录、团队隔离、查看者写入限制、种子数据、样本门槛、CSV 导入、标签、规则降级、后端模型代理 JSON 解析、建议采纳、日历更新、发布反馈、审计、脱敏 CSV、交接包和 PDF 导出。

| 阶段 | 快速检查 |
|---|---|
| 0 工程与启动 | `docker compose up --build` 或 `./start.sh`；打开 `http://localhost:8000` 并创建负责人账号。 |
| 1 数据底座 | 录入一条内容后查看内容表；`GET /api/stats/overview` 可在 Swagger `/docs` 中查看实时汇总。 |
| 2 AI 与 OCR | 不配置模型点击“生成建议”，应显示“规则分析（未使用大模型）”；在模型设置页测试真实连接。上传一张截图，核对 OCR 草稿并确认入库。 |
| 3 执行闭环与 PDF | 生成并采纳建议，日历刷新；标记发布并回填，内容表和采纳收益随之变化；“导出 PDF 复盘”得到 PDF 文件。 |
| 4 分析与沉淀 | 调整样本门槛、查看标签和基准、添加 A/B 假设、检查审计日志和脱敏 CSV。 |
| 5 部署验收 | 运行上述 27 项自测；确认弱网 / 无模型时规则建议可用，手机宽度下主要页面可操作。 |

## 数据库和迁移

默认使用 SQLite。结构由 Alembic 管理，启动时自动执行 `alembic upgrade head`。如需 PostgreSQL，将 `.env` 中的数据库地址改为 SQLAlchemy 格式，例如：

```env
DATABASE_URL=postgresql+psycopg://用户名:密码@数据库地址:5432/arts_smart
```

迁移命令：

```bash
.venv/bin/alembic upgrade head
.venv/bin/alembic current
```

## 当前实现边界

- 平台后台截图 OCR 使用 Tesseract 通用文字和数字识别，不针对某个平台训练；遮挡或特殊版式需手动修正。
- 评论倾向与关键词目前使用本地词表做轻量提示，只有团队主动录入的评论摘录会参与分析；它不代表完整语义理解。
- 报告中的图形是后端根据真实聚合数据生成的柱状图；报告只包含当前团队自有数据。
- 多人部署请配置 HTTPS、强随机 APP_SECRET、数据库备份和防火墙。当前应用不包含第三方平台自动拉数、全网抓取、观众画像、自动发布或审批工作流。
